# Grimoire

L'appli de maths de 5e, façon grimoire.

## Mettre en ligne (GitHub Pages)

1. Dépose tous les fichiers de ce dossier à la racine du dépôt (bouton **Add file → Upload files**).
2. Dans le dépôt : **Settings → Pages → Build and deployment**.
   - Source : **Deploy from a branch**
   - Branch : **main**, dossier **/ (root)** → **Save**
3. Après une ou deux minutes, l'adresse s'affiche en haut de la page Pages : `https://TONPSEUDO.github.io/NOM-DU-DEPOT/`

## Sur le téléphone (Android, Chrome)

Ouvrir l'adresse dans Chrome → menu ⋮ → **Installer l'application** (ou « Ajouter à l'écran d'accueil »).
L'icône du grimoire et le nom « Grimoire » apparaissent sur l'écran d'accueil.

## Mettre à jour

Redéposer les nouveaux fichiers au même endroit (ils remplacent les anciens).
La progression de l'enfant (étoiles, créatures…) est gardée sur son téléphone.
